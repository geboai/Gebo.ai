Inputs:

{question}

{documents}
OUTPUT RULES:
Your task is to output ONLY a single JSON object (no markdown, no extra text).
You must set "responseRoutingDecision" to exactly one of:
- "PURE_LLM_RESPONSE"
- "RAG_LLM_RESPONSE"
- "DEEP_SEARCH_RESPONSE"
- "TOOLS_USE_RESPONSE"

{deepSearchDataSources}
- tools list (may be empty):
{toolsList}
Decision rules (apply in this exact priority order):
1) TOOLS_USE_RESPONSE:
   Choose this if the user explicitly asks to use tools mentioning to perform an action indicated in the tools list OR the question cannot be answered without using one of the provided tools.
2) DEEP_SEARCH_RESPONSE:
   Choose this if the user explicitly requests a search/report/research/in-depth/deep analysis (in english or expressing the same concepts in other languages), OR asks for citations/sources across multiple documents/data sources  (in english or expressing the same concepts in other languages), OR asks to analyze/compare a broad corpus  (in english or expressing the same concepts in other languages).

3) RAG_LLM_RESPONSE:
   Choose this if the answer is not fully supported by training knowledge OR the currently provided in the document list, and retrieval from a knowledge base is likely sufficient (no deep multi-source analysis required).
4) PURE_LLM_RESPONSE:
   Choose this if the answer is fully achievable using training knowledge and/or already provided chat/doc fragments.

- expandDocuments: include ONLY document codes that exist in the chat history.
- queryRewritings: fill both semantic search query rewrite and full text keywords search query rewrite ONLY when responseRoutingDecision is RAG_LLM_RESPONSE .
- deepSearchDataSourceCodesToAnalyze: fill ONLY when responseRoutingDecision is DEEP_SEARCH_RESPONSE (otherwise []).
- toolsToUse: fill ONLY when responseRoutingDecision is TOOLS_USE_RESPONSE (otherwise []).

- If tools list is empty you cannot choose TOOLS_USE_RESPONSE.  
CONFIDENCE:
Return a confidence score in [0.00..1.00] representing how certain you are that the chosen route is correct.
Compute it deterministically from the rubric:
Start at 0.50
Add +0.10 for each signal among A..E that is clearly consistent with the chosen route (score=2).
Add +0.05 for each signal among A..E that is somewhat consistent (score=1).
Subtract -0.10 for each strong ambiguity or missing detail that could flip the route.
Clamp to [0.00..1.00].
Also return a short list of ambiguity reasons (max 3). If none, return an empty list.
