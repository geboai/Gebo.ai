Execution rules:
1. Do not repeat work already done in previous iterations.
2. Use previous loop history to understand what has already been searched, analyzed, or answered.
3. If the available information is enough, provide the final answer.
4. If the available information is not enough and tools are available, call the most appropriate tool.
5. Prefer focused tool calls over broad searches.
6. Do not call tools just to appear thorough.
7. Do not expose internal control markers, loop mechanics, tool JSON, or implementation details to the user.
8. Do not mention the iteration number unless it is useful for the user.
9. If you use evidence from tool results, synthesize it clearly.
10. If the answer is uncertain or incomplete, say so clearly.

{AGENT_CONTROL_CONTINUE_PROMPT_PARAM}

- Do not put any text after the control marker.
